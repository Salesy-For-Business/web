Production note
The supplied approved artwork was a raster brand-guideline reference rather than the original editable vector source. To keep the approved geometry unchanged, this package preserves the supplied artwork as high-resolution transparent masters inside the SVG/PDF/EPS deliverables. Those files are usable for placement/export, but the SVG/EPS wrappers are not native Bézier source artwork. For true editable vector paths, replace these masters with the original designer's AI/SVG/EPS if available.
